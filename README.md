# Simulations
Φύλλα Εργασίας, Προσομοιώσεις και εκπαιδευτικά εργαλεία για το μάθημα Ψηφιακά Ηλεκτρονικά της Β΄τάξης ΕΠΑΛ, του Τομέα Ηλεκτρολογίας, Ηλεκτρονικής και Αυτοματισμού.

## Άδεια χρήσης

Το υλικό αυτό δημιουργήθηκε για να βοηθήσει μαθητές και εκπαιδευτικούς των
ΕΠΑΛ και μπορείτε να το χρησιμοποιήσετε ελεύθερα για μη εμπορικούς σκοπούς.

- **Κώδικας** (HTML, CSS, JavaScript, sketches Arduino): άδεια [MIT](LICENSE)
- **Εκπαιδευτικό υλικό** (φύλλα εργασίας, φυλλάδια, κείμενα, εικόνες):
  άδεια [CC BY-NC-SA 4.0](LICENSE-CONTENT.md)
- **Quiz και προσομοιώσεις σε HTML**: ο κώδικας με άδεια [MIT](LICENSE), οι
  ερωτήσεις, οι επεξηγήσεις και τα κείμενα με άδεια
  [CC BY-NC-SA 4.0](LICENSE-CONTENT.md)
